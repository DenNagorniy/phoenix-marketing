# Main Site Architecture

Этот репозиторий владеет публичной презентацией Phoenix Marketing.

## Разрешено

- описание услуги;
- публичный offer ladder;
- публичные proof-ссылки;
- утверждённая презентация;
- контактный CTA;
- публичные визуальные assets.

## Не принадлежит этому репозиторию

- client-specific demo pages;
- внутренний outreach register;
- Truth Registry клиентов;
- lead data;
- backend integrations;
- credentials;
- private client materials.

## Navigation contract

Основной сайт может ссылаться на публичный demos-сайт, PDF-презентацию и рабочий контакт. Каждая ссылка проверяется после deployment.
