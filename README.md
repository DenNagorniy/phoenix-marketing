# Phoenix Marketing

Публичный основной сайт Phoenix Marketing.

## Назначение

Этот репозиторий содержит только публичную витрину услуги: кто мы, какую проблему решаем, что такое маркетинговая связка, форматы работы, презентацию, ссылки на демонстрации и контактный CTA.

Демонстрационные сайты и внутренние материалы находятся в отдельном репозитории phoenix-marketing-demos.

## Структура

/
- index.html — главная страница Phoenix Marketing
- assets/ — публичные изображения, шрифты и иконки
- docs/ — публичные тексты и архитектурные заметки
- presentation/ — публичная PDF-презентация и исходники
- styles.css — стили главной страницы
- script.js — публичная интерактивность
- README.md

## Правила

- Не хранить .env, API-ключи, лиды, CRM-экспорты и персональные данные.
- Не публиковать внутреннюю стратегию, Truth Registry клиентов или служебные заметки.
- Все коммерческие утверждения должны быть проверены.
- Ссылки на демо должны вести только на материалы, разрешённые для публичного просмотра.
- Production backend сюда не добавляется.

## Deployment

Сайт публикуется через GitHub Pages. Workflow `.github/workflows/deploy-pages.yml` запускается автоматически после push в `main`.

## Статус

PUBLIC SITE — production-витрина публикуется из ветки `main` через GitHub Actions.
